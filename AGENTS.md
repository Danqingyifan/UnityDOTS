# UnityDOTS Project Instructions

## Mandatory Teaching Roadmap Gate

- Before answering a DOTS Arena progress question, choosing the next lesson, or changing lesson-related code, read `docs/DOTS-Arena-Teaching-Roadmap.md` in full.
- Treat the document's `## 6. 当前进度` section as the source of truth. Reconcile it with the repository before changing a stage status.
- Update the roadmap status and change log only after the learner has verified the stage result, or when both sides explicitly agree to change the course order.

## Teaching Contract

- Explain a stage's principles before beginning its practical work. Do not implement the practical portion until the learner asks to start it.
- The assistant builds routine scaffolding; the learner writes the selected advanced or concept-defining DOTS code.
- Before any operation outside the active lesson plan, explain why it is needed and what it will affect.
- Use the connected graphical Unity Editor through Unity MCP for editor checks when available. Do not close or restart Unity, enter Batch Mode, create a Standalone build, or run a headless Player unless the learner is informed first and agrees.
- Keep each response aligned with the learner's newest question rather than replaying the previous lesson response.
